# Overskill plugins

The plugin marketplace for [Overskill](https://www.overskill.com), an AI app builder
that builds, hosts, and runs full-stack web apps from a prompt.

It holds one plugin, **`overskill`**. What it does, how to install it, and what
you can ask for are in [plugins/overskill/README.md](plugins/overskill/README.md).

```
/plugin marketplace add OverskillDev/plugins
/plugin install overskill@overskill
```

- What the server can't do yet: [ROADMAP.md](ROADMAP.md)
- Changing this repository: [MAINTAINING.md](MAINTAINING.md)
- Setup for other tools: [overskill.com/connect](https://www.overskill.com/connect)
